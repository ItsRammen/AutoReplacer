# AutoReplacer app

This folder holds the AutoReplacer Android app: [Open Headunit](https://github.com/andreknieriem/open-headunit), reworked into the phone side of an **Auto+ Show (Garmin USB Link)** head unit. It is a hard fork and is released under the GNU AGPL v3.

- What the project is, how it works and how it was worked out: the [project README](../README.md).
- What changed on top of the Open Headunit import: [`UPSTREAM.md`](UPSTREAM.md).
- User-facing change history: [`CHANGELOG-AUTOREPLACER.md`](CHANGELOG-AUTOREPLACER.md).
- Open Headunit's own README, kept for reference: [`README-OPEN-HEADUNIT.md`](README-OPEN-HEADUNIT.md).
- Build: `./gradlew :app:assembleGithubDebug` (JDK 17 and the Android SDK; see the project README).
